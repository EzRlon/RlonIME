一、这个软件做什么
------------------
面向工程设计、制造与展示行业从业者的中文词汇助手。两条主线能力：

  1. 中文输入增强 —— 全系统接管键盘，敲拼音直接出专业术语候选，
     数字/空格选词，Tab 上屏英文，Ctrl+数字 上屏「中文 English (标准号)」。
  2. 选中即译 + 记忆闭环 —— 选中中文片段按 Ctrl+Alt+T，就地替换成符合
     当前行业与整句语境的英文；译完不满意就改，改完按 Ctrl+Alt+M 标记，
     这条译法永久进入本机记忆库，下次同样的中文直接命中，不再走 AI。

二、隐私声明
--------------------------
1. 默认不联网。「免费翻译」和「AI 翻译增强」都是默认关闭的；第一次用到时
   会让你显式确认开启一次，不开就不会发起任何网络请求。
2. 词库检索、记忆库匹配、术语对齐全部在本机完成，不上传。记忆库在
   %APPDATA%\RlonIME\memory.db，只增不删，卸载也不会删除它。
3. 开启「免费翻译」后，你选中的那一段中文会被发给这些在线服务换取译文：
   腾讯 transmart、有道，以及 MyMemory、Google 的免 Key 翻译端点。
   其中 MyMemory 与 Google 的端点在境外，选中的文本会被传到境外服务器；
   图纸、合同这类内容请先自己确认能不能发。
4. 开启「AI 翻译增强」并填入 API Key 后，本地词库和记忆库都查不到时，
   选中的中文（连同当前行业岗位名称、命中的术语对照）会发给你自己填写的
   那个大模型端点；发到哪里、发什么由你填的地址决定。
5. 想完全不联网：按 Ctrl+Alt+S 关掉「AI 翻译增强 / LLM」，再在设置里关掉
   「免费翻译」。两项都关 = 本软件不联网。
6. 键盘钩子只用来识别拼音组合和热键，不记录、不保存、不外发按键内容。
   崩溃日志只存在本机 %APPDATA%\RlonIME\logs，只有版本号和堆栈，不含
   按键内容、剪贴板内容和用户文本，也不会自动上传。

三、开源组件与许可
------------------
本软件复用了以下成熟开源组件，在此致谢：

  PySide6 (Qt for Python)  图形界面               LGPL v3
  pypinyin                 汉字转拼音               MIT
  pygetwindow              窗口信息读取             BSD
  psutil                   进程与服务信息           BSD
  pyperclip                剪贴板（非 Windows 兜底） BSD
  keyboard                 热键兜底通道             MIT

关于 PySide6 / Qt 的 LGPL v3 合规说明：

  - 本软件以**动态链接**方式使用 Qt：安装目录下 Qt 运行库为独立 DLL
    （PySide6/*.pyd 与 Qt6*.dll），未做任何静态链接或修改。
  - 用户可用同版本或兼容版本的 Qt DLL 自行替换（relink），满足
    LGPL v3 第 4 条的组合作品分发条款。
  - Qt 完整源代码可向 Qt 官方获取（https://download.qt.io/）。
  - 本软件闭源部分与 Qt 库相互独立，不因使用 Qt 而改变授权。
