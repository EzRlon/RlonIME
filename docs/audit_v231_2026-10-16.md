## 二、软件立意复盘（这次审计的尺子）

立意一句话：**这不是"又一个输入法"，而是贴着光标工作的专业领域词汇助手。**
三条支线（按优先级）：

1. **工程术语输入**（主）：任意软件里敲拼音出专业术语，中英一键切换、带国标号；
2. **选中即译 + 记忆闭环**（护城河）：选中中文 → 就地变英文；改过的译法永久入库，
   同一个中文下次直出（用户译法 > AI 初稿）；
3. **常规输入**（v2.3 补位）：行业词没命中时不再"让位"，而是像正常输入法一样可用，
   普通词同样带英文——**"专业+日常"双态**，这是与搜狗/微软拼音的错位点：他们做不好
   术语与翻译，而我们做不好整句联想——v2.3 之后，后一块短板被补到"够用"。

**立意校验的两个提醒**：
- 双态并存后，"工程输入法"的对外口径要更突出「工程术语 + 翻译 + 记忆」而不是"能打中文"
  （后者通用输入法免费且更强）；
- 记忆闭环的护城河目前**没有可迁移性设计**（换机器即失去全部积累）——见 F4。

## 四、现状实测数据（v2.3.1）

- **测试**：源码七套全绿（ime 56 / leak 61 / common 64 / assist 51 / single 7 / e2e 17 /
  UI冒烟含多屏断言）；安装版 live 两套全绿（14 + 12）。
- **体积**：安装包 26.5MB（v2.1 36.4MB→-27%）；安装后 55MB（v2.1 120MB→-54%）。
  UPX 压 26 个非 CFG 文件（CFG 由 PyInstaller 自动跳过，不破坏保护）。
- **检索延迟**：平均 0.21ms / 最慢 0.30ms（82k 通用词库载入后）。
- **内存**：引擎进程 ≈110MB（基础 25MB + 专业词库&拼音 57MB + 通用词库 28MB）；
  通用层可在"未依赖时跳过"，不影响可用性。
- **数据**：15 行业词库 1,591 条 + 工程共享层 326 条 + 通用层 82,098 条。

## 六、建议新增功能（立意导向，按优先级）

### N1【P0·核心】选区悬浮「译」钮（补上规格⑦）
- 交互：鼠标拖选中文（任意软件）→ 松手后 200ms 在选区右下浮出 28px 圆钮「译」→
  单击 = 现有五级管线翻译 + 就地替换；1.5s 无操作自隐；Esc 取消。
- 方案（全部复用现有件）：`WH_MOUSE_LL` 低层鼠标钩子（与键盘钩子同栈，hMod 已踩平）
  监听 LBUTTONUP → `read_selection()`（已有无损剪贴板取字）→ 判定含中文且 ≥2 字 →
  `TranslateFloatBtn`（frameless + WS_EX_NOACTIVATE，复用 bar 的 make_no_activate）随鼠标定位；
  点击触发 main 里已有的 `translate_selection()` 流程。多屏定位按 v2.3.1 的"光标所在屏"口径。
- 价值：把"贴着光标"从口号变成第一眼可见的能力；翻译不再依赖背热键。
- 风险控制：默认对"选中即弹"做 300ms 防抖 + 仅当选中含中文时弹；可在 config 关。

### N2【P1】术语一致性检查（框选英文 → 标注不一致）
- 选一段英文 → 热键/译钮菜单 → 与词库标准译名比对，列出「非标准用词 → 建议标准译名」。
- 复用：`to_english` + `translate.py` 的术语对齐模块（已有"术语强制对齐"逻辑，反向用）。
- 价值：直接命中"图纸上同一零件两种叫法比句子漂不漂亮严重得多"这条红线。

### N3【P1】一键备份/恢复（见 F4）——与 F2/F6/F8 合并成一个「关于弹窗增强包」（1 天打包完成）。

### N4【P1】更新通道（见 F2）+ 词库版本号（词库可独立升级，不动主程序）。

### N5【P2】常用工程短语/图注模板
- 预置"图注常用句"（如 `按图施工`→`Per Drawing`、`未注尺寸以3D模型为准`、
  `ALL DIMENSIONS IN MM` 反向等 30–50 句），拼音/中文前缀触发，Tab 出英文。
- 价值：工程邮件/图纸注释的整句场景，与术语库形成"词→句"的自然延伸。

### N6【P2】英中反查扩展至通用词库
- 现状英文反查只覆盖专业/共享层；把通用层 top 2 万条纳入 en 索引（内存可控），
  `typing "plan" → 方案/计划`。配合 F10 的拆分加载一起做。

### N7【P3】整句翻译记忆的主动建议
- 上屏中文句（分段候选）后可提示"按 Q 可整句翻译"，引导发现翻译管线（低频、免打扰）。
