## 一、先看实测证据（数据说话）

### 1.1 你真实敲过的词（usage.db Top 15）

```
沉孔 48 | 圆角 11 | 倒角 9 | 螺纹孔 8 | 埋头孔 8 | 基准面/轴/点 各 8
拉伸凸台/拉伸切除/旋转凸台/旋转切除/扫描特征/放样特征 各 8 | 型材 4
```

**解读**：两大真实场景已浮出水面——
- **S2 特征树/属性命名**（拉伸凸台、扫描特征…10/15 条）：在 SolidWorks 里给特征命名，
  是当前最高频的真实用法；
- **S3 图纸标注词**（沉孔、圆角、倒角、螺纹孔…）：工程图标注是第二高频。
- 另：memory.db 0 条 → **「选中即译」记忆闭环几乎还没被用起来**（能力在、入口难找）——
  这直接给 N1 悬浮译钮的立项增加了证据。

### 1.2 CAD 命令行高危实测（本轮新发现，最优先）

对 AutoCAD 用户最常见的命令别名逐一在候选层实测（mechanical+drawing 场景）：

| 键入 | 现在弹出的候选（Top4） | 危害 |
| ---- | -------------------- | ---- |
| `l`（LINE） | **总长**、提单、信用证、装箱单 | 习惯性按空格确认命令 → **"总长"被插进命令行** |
| `li`（LIST） | **梁**、立柱、离、理 | 同理，空格 → "梁" |
| `line` | **中心线**、引出标注、虚线、剖切线 | 回车/空格 → "中心线"插入 |
| `c`（CIRCLE） | **商业发票**、信用证、销售合同 | 空格 → "商业发票" |
| `m`（MOVE） | **模数**、呣、磨削、毛坯 | 同上 |
| `e`（ERASE） | **弹性模量**、色差、急停按钮 | 同上 |

代码核实（ime.py:552 + bar.py commit_index）：**存在候选时，空格/回车 = 选词上屏**
（`l`+空格 → 总长）。这不是理论风险：AutoCAD/中望/CAXA 用户敲着英文别名、
候选条闪个不停，一次空格就写错命令——**对"支持 AutoCAD"这条线是口碑级事故**。
SolidWorks 侧影响小一级（单字母会顶掉 SW 快捷键如 `s`），但同类。

## 二、场景地图与建议（S1–S8）

每个场景给：现状 → 痛点 → 建议（含价值/成本）。

### S1 CAD 命令行字母冲突【高危 · 建议最先修】

- **方案 A（推荐主件）：CAD 软件自动直通模式**
  - 识别到前台 ∈ CAD 集（acad/caxa/zwcad…，场景探测已有此能力）→ 默认**不吞字母**，
    交还系统（和微软拼音共存，命令别名原样直通）；
  - 需要打中文术语时按 `Ctrl+Space` **临时激活**我们的输入法；
  - **空闲 5s 自动回落直通**（可配置）——解决"打完了忘记关"的经典翻车；
  - 候选条顶行 ⏸ 状态同步显示「CAD 直通」；
  - 成本 ≈ 1 天（场景探测 + 状态机 + 回归），配置项 `softwares.*.ime_passthrough`。
- **方案 B（通用兜底）：非拼音精确命中不"吃"空格**
  - 规则：空格/回车在「无 full_pinyin/abbr 精确命中」时**直出原文**，不再选词；
    数字键仍可主动选（`counter`+空格 → 直出 "counter"；`counter`+`1` → 沉孔）。
  - 收益：`l`/`line`/`co` 等全部安全；顺带修复"任何程序里打英文短词被中文截胡"。
  - 代价：改掉"空格选词"对前缀/英文命中的既有语义（README 需同步）；
    单音节中文（我/的）不受影响——它们本来就是精确命中。
  - 成本 ≈ 0.5 天。
- 建议 A+B 都做：A 治 CAD 根、B 治全场景。

### S2 特征树 / 属性命名【当前最高频 · 现状已可用】

- 现状：SW 特征名（拉伸凸台等）词典已覆盖，`Ctrl+数字` 可出「中文 English」组合名；
- 轻量建议：**命名增强**（低优先）——上屏组合改为「中文_英文」还是「中文 English」按软件规范可配；
  零件名模板（`类型-规格-材料`，如"法兰-Φ50-45钢"）留作 P2 观察项，不做重型功能。

### S3 图纸技术要求 / 图注句库【强烈建议下一个做】

- 痛点：每张图纸的技术要求是 8–15 行固定句（"未注圆角 R2"、"去毛刺锐边倒钝"、
  "未注公差按 GB/T 1804-m"、"表面处理：阳极氧化本色"…），现在要逐词拼；
- 建议：**技术要求句库**（30–50 句，中英对照+标准号）
  - 触发：拼音首字母/关键词（`wzYJ`→未注圆角…）或短代码；`Tab`=英文，`Ctrl+数字`=中英全句；
  - 出处：从你现有图纸的"技术要求"块提炼 + 常用国标句；存为独立 json（用户可增改）；
  - 价值：直接命中图纸主线，单张图省 2–5 分钟；成本 ≈ 1 天（数据 0.5 + 引擎接线 0.5）。

### S4 对外沟通（邮件/微信/报价）【入口问题 > 能力问题】

- 现状：翻译能力具备，但只有热键入口（memory.db 0 条 = 没用起来）；
- 建议：**N1 悬浮译钮**（讨论稿一致保留 P0）——选中即浮"译"钮，单击就地翻译；
- 附（低优先）：译文风格 micro 提示（技术直译/商务）——等 LLM 稿质量反馈再说。

### S5 读英文资料（标准/客户图纸/邮件）→ 反向划译【建议随 N1 一起做】

- 现状：管线是"中→英"单向（translate.py 全链路核实：无英→中分支）；
- 建议：悬浮钮做**双向自动判方向**——选中是中文→出英文；选中是英文→出中文
  （英文侧走 LLM + 术语反查对齐，`沉孔`↔`Counterbore` 双向映射词库已具备）；
- 价值：看 ISO/ASME、读客户邮件是工程岗每天的事；成本 ≈ +0.5 天（复用悬浮钮壳）。

### S6 工艺 / SOP / 质量文档【词库已覆盖 · 不立项】
v2.3 的 工艺/表面处理/流程 词库已覆盖 80%；句骨架等有真实反馈再做。

### S7 BOM / 明细表【收敛进 N2，不单独立项】
批量翻译重、低频；与"术语一致性检查（框选英文→标出非标准译名）"合并排期。

### S8 会议纪要 / PPT【不立项，明确不做】
与立意无关，不做。
