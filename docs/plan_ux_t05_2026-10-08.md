## 三、契约与依赖（T05 重写硬约束）

1. **构造签名**：`SettingsDialog(engine=..., ime=..., parent=None)` —— `main.py:301` 调用点不变。
2. **信号**：`settings_changed = Signal(dict)` 不变 —— `main.py:302` 接线不变。
3. **payload 结构**：`emit(result)` 必须含 `industry` 字段（`main.py:312` 直接消费）；
   其余 ime/llm 段由 `main.py` 走 `get_config(reload=True)` 从 `config.json` 读 →
   **settings.py 必须把改动写回 `config.json`**（复用 `config._persist` 通道），否则 reload 读不到。
4. **视觉**：纯 QSS，12px 圆角卡片 + tonal 配色，不引新依赖；NOACTIVATE 窗口属性保持。
5. **design.py 令牌**：只追加 `MD3_*` 组，不破坏现有 `LIGHT/DARK/PRIMARY` 系列（`bar.py` 已用）。

## 五、风险与缓解

- **R1 契约漂移**：payload 漏 `industry` / 未写回 `config.json` → `main.py` reload 失效。
  缓解：T05b 首步 `Read main.py:307-321` 锁定契约；emit 后断言 `config.json` 落盘。
- **R2 记忆库卡范围**：设计文档 §七.4 标注「原设置中心 29KB 内容未逐行审，默认不迁移」。
  缓解：PM 确认入口清单，白名单内才迁；T05d 标 P2，可后置不阻塞主线。
- **R3 MD3 令牌破坏 bar.py**：`design.py` 改动须不动现有 `PRIMARY` 系列。
  缓解：只追加 `MD3_*` 组；`Grep bar.py` 用到的令牌确认无删改。
- **R4 打包回归**：T05 改 UI 不碰内核，但仍需 `dist12` 打包 + 安装版复测（钩子 `hMod=NULL` 红线）。
