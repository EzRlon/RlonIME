## 一、产品定位调整（最高优先级变更）

| 项 | 旧口径 | 新口径 |
|---|---|---|
| 目标市场 | SolidWorks 机械设计师首发 | **通用多行业产品**，SW 仅首发场景 |
| 主轴维度 | 行业 + 工作软件双维度 | **行业是唯一用户可见维度**（机械/橱窗/包装/财务…） |
| 工作软件 | 托盘菜单「指定工作软件」可手动选 | **UI 隐藏**，仅后台自动检测用于加权；普通用户无感 |

## 三、交互稿（文字排版模拟）

### 3.1 候选条 · 输入态（重做，反馈 13/14/4/5）

```
┌─ 拖动把手 ────────────────────────────────────────────────────────────┐
│ ⠿  chenkong                                              ⚙ │
│ ┌─────────┐  ← 英文译法区：在中文正上方，多译法纵向列            │
│ │★Counterbore · GB/T 152.2  [推荐] │  ← 当前译法高亮，点击=英文上屏  │
│ │  Spotface                       │  ← 次译法，点击同样上屏        │
│ └─────────┘                                                │
│ [1 沉孔] [2 埋头孔] [3 螺纹孔] [4 锪平]      中文12pt / 英文10pt │
└──────────────────────────────────────────────────────────────┘
        悬停任一胶囊 → 说明卡：
        ┌──────────────────────────────┐
        │ 沉孔  Counterbore            │
        │ 用于内六角螺钉头沉入，GB/T 152.2 │
        │ 推荐理由：当前场景=工程图标注，    │
        │ 你最近用过 3 次               │
        └──────────────────────────────┘
```
- 选中项变化（方向键/鼠标/数字键）→ 英文译法区**实时联动**（反馈 5）
- 点击英文译法 → 该译法上屏到光标处（反馈 2）；点击中文胶囊 → 中文上屏
- 候选条图标精简：只留 ⚙ 设置（反馈 14）
- 「推荐」标 = 打分第一名且与第二名分差 > 阈值（防止两个都差不多时误导）

### 3.2 候选条 · 联想态（上屏后，反馈 9）

```
┌───────────────────────────────────────────┐
│ ⠿  沉孔 ✓  联想→ [通孔] [平孔] [螺纹孔]    Esc 关闭 │
└───────────────────────────────────────────┘
```
- 独立**联想槽位**，与候选池**物理隔离**（独立数据结构、独立渲染路径）
- 数据源：① 人工维护关联对（沉孔→通孔/平孔）② 同场景标签共现，**均须过白名单校验**
- 联想词点击/数字键上屏；3 秒无操作自动收起
- 🔴 红线：联想数据永远不得并入 engine.search 候选池；test_leak.py 增补联想隔离用例

### 3.3 词库外中文 ·「译」候选（反馈 6）

```
输入「限位挡块」（词库无）→
[1 限位挡块] [译 Limit stop →]     ← 自动生成「译」候选，带箭头标识
```
- 开 AI：走大模型；不开 AI：记忆库模糊 + 术语拼接；两者都无时「译」候选**不出现**（不伪造）
- 选「译」→ 英文上屏 + 进记忆库（沿用 store_llm_draft 逻辑）

### 3.4 设置中心 · Material You 观感（反馈 16）

```
┌ 智语设置 ────────────────────────────────┐
│ ╭─ 行业身份（大卡片， tonal 色块）──────╮ │
│ │ 机械工程师  ▸  结构 / 设计师          │ │
│ ╰──────────────────────────────╯ │
│ ╭─ 输入 ─────────────────────────╮ │
│ │ 字号  中文 [12▾]  英文 [10▾]      │ │
│ │ 候选条跟随光标          (●━━) 开  │ │  ← MD3 开关
│ │ 记住拖动位置            (●━━) 开  │ │
│ ╰──────────────────────────────╯ │
│ ╭─ 快捷键（左手位）─────────────────╮ │
│ │ 翻译选区   Ctrl+Alt+Q   [修改]     │ │
│ │ 标记纠正   Ctrl+Alt+W   [修改]     │ │
│ │ 面板      Ctrl+Alt+E   [修改]     │ │
│ │ 切行业    Ctrl+Alt+A   [修改]     │ │
│ │ AI 开关   Ctrl+Alt+S   [修改]     │ │
│ ╰──────────────────────────────╯ │
│ ╭─ AI 翻译 ───────────────────────╮ │
│ │ 服务商 [智谱GLM(免费)▾]  Key […]  │ │

└──────────────────────────────────────┘
```

- **不出现「指定工作软件」任何入口**（反馈 12）

## 五、架构红线（写入 PRD，全程有效）

| # | 红线 |
|---|---|
| 1 | **候选绝不伪造**：任何兜底/联想/「译」候选必须与用户输入同源；test_leak.py 看门狗每轮回归必跑，本轮新增精确命中降噪与联想隔离用例 |
| 2 | 候选窗必须 WS_EX_NOACTIVATE（拖动改造不得破坏） |
| 3 | 上屏只用 SendInput Unicode，不写剪贴板 |
| 4 | SetWindowsHookEx 的 hMod 必须传 NULL |
| 5 | 吞 keydown 必须配套吞 keyup |
